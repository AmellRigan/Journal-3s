# Journal Hero

Первая рабочая версия Android-приложения для личного учёта времени и повседневных дел. Интерфейс — тёмная готическая палитра с бордовыми и золотистыми акцентами.

## Что есть в приложении

- Учёт времени по методу 3С: Работа / Учёба, Быт, Отдых.
- Секундомер с сохранением завершённых сессий.
- Цели, ежедневные задачи и привычки.
- Личный дневник.
- Список упражнений для тренировок и йоги.
- Сводная статистика.
- Резервное копирование данных в JSON и восстановление из файла.

Данные хранятся локально на устройстве в WebView localStorage. Для переноса на другой телефон используйте экспорт резервной копии.

## Сборка APK

Сборка запускается автоматически при push в ветку `journalhero-black-red`, а также вручную через GitHub Actions.

1. Откройте вкладку **Actions**.
2. Выберите запуск **Build APK**.
3. Дождитесь статуса **Success**.
4. Откройте завершённый запуск и найдите блок **Artifacts**.
5. Скачайте `JournalHero-debug-apk` и распакуйте ZIP. Внутри находится `app-debug.apk`.
6. Установите APK на Android. Если система спросит, разрешите установку приложений из этого источника.

## Технические параметры

- Java 17
- Android Gradle Plugin 8.2.2
- Gradle 8.4
- minSdk 24 (Android 7.0)
- targetSdk 34
- applicationId: `com.hero.journal`

## Структура

- `app/src/main/java/com/hero/journal/MainActivity.java` — Android WebView оболочка.
- `app/src/main/assets/web/index.html` — интерфейс и локальная логика приложения.
- `app/build.gradle` — конфигурация Android-модуля.
- `.github/workflows/build.yml` — CI-сборка APK.
