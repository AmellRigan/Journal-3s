# Журнал Героя

Android-приложение на WebView. Интерфейс в атмосфере Dragon Age II.

## Сборка через GitHub Actions (только телефон)

1. Создай репозиторий на **github.com**
2. Загрузи все файлы проекта (сохраняя структуру папок)
3. Перейди на вкладку **Actions** → **Build APK** → **Run workflow**
4. Через ~4 минуты: жми на завершённый запуск → **Artifacts** → скачай ZIP с APK
5. Установи APK на телефоне (разреши установку из неизвестных источников)

## Технические детали

| Параметр | Значение |
|---|---|
| Язык | Java 17 |
| AGP | 8.2.2 |
| Gradle | 8.4 |
| minSdk | 24 (Android 7.0) |
| targetSdk | 34 (Android 14) |

## Обновление UI

Весь интерфейс в одном файле:
`app/src/main/assets/web/index.html`

Отредактируй на GitHub → commit → Actions пересоберёт APK автоматически.
